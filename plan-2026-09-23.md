## Task 1 — Learn context windows (also fixes Task 4)

**Goal:** parse provider context-length 400s, learn the model's real window, store

### 1a. `src/provider/openai.lua` — add a parser + learner (mirror the reply-ceiling code)

Add near `M.rememberMaxTokens` (`config` and `log` already required at the top):

```lua
	-- The context window a refusal names, or nil. Mirrors ceilingFromMessage for the
	-- input side. No endpoint publishes a window; it only appears in the 400 that
	-- comes back when a prompt overflows it, worded differently everywhere:
	--   "maximum context length is 128000 tokens. However, your messages resulted in
	--    130000 tokens (5000 in the completion)"  -> 128000
	--   "prompt is too long: 250000 tokens > 200000 maximum"  -> 200000
	-- Gated on a context signal so a max_tokens 400 cannot teach a phantom window,
	-- and anchored so the window is read rather than the request size or completion
	-- budget beside it.
	function M.contextWindowFromMessage(message)
		local text = tostring(message or ""):lower()
		local isContext = text:find("context length", 1, true)
			or text:find("context window", 1, true)
			or text:find("context_length_exceeded", 1, true)
			or text:find("prompt is too long", 1, true)
			or text:find("maximum context", 1, true)
			or text:find("too many tokens", 1, true)
			or text:find("reduce the length of the messages", 1, true)
		if not isContext then return nil end
		local patterns = {
			"maximum context length is%s*(%d+)",
			"maximum context length of%s*(%d+)",
			"context length of%s*(%d+)",
			"context window of%s*(%d+)",
			">%s*(%d+)%s*maximum",
			"maximum of%s*(%d+)%s*tokens",
			"at most%s*(%d+)%s*tokens",
			"maximum.-(%d+)",
		}
		for _, pattern in ipairs(patterns) do
			local found = tonumber(text:match(pattern))
			-- Floored high so a misparse of a small number cannot crush the context.
			if found and found >= 8000 then return found end
		end
		return nil
	end

	-- Stores a learned window keyed by lowercased model id in the same
	-- agent.forceContext map the badge and compaction budget already read. Lowers an
	-- existing value rather than raising it: a refusal proves the real window is at
	-- most this, and a manual 1M that never fits is exactly what this corrects.
	function M.rememberContextWindow(record, window)
		window = tonumber(window)
		if not window or window ~= window or window <= 0 or window == math.huge then return end
		local id = tostring(record and record.model or ""):lower()
		if id == "" then return end
		local contexts = config.get("agent.forceContext", {}) or {}
		local previous = tonumber(contexts[id])
		if previous and previous > 0 then window = math.min(window, previous) end
		if tonumber(contexts[id]) == window then return end
		contexts[id] = window
		config.set("agent.forceContext", contexts)
		log.info("provider", string.format("%s: learned context window %d for %s",
			record.label, window, tostring(record.model)))
	end

	-- Reads a failed response and learns a window when it is a context-length
	-- refusal. Safe on any failure; both adapters call it.
	function M.learnContextWindow(record, res)
		if not res then return nil end
		local window = M.contextWindowFromMessage(M.errorText(res, nil))
		if window then M.rememberContextWindow(record, window) end
		return window
	end
```

		local function openContextInspector(target)

## Dialect reminders for the executing agent

- Keep the Luau dialect: tabs, no `continue`/`goto`, no `::`/`->`, use
  `string.format` (no backtick interpolation), no `//` or digit separators.
- Every module stays `return function(env) ... end`; don't read a global the
  allowlist doesn't name (`test/check.lua` enforces this).
- The context-window floor (8000) and the min-lowering behavior in
  `rememberContextWindow` are deliberate — don't relax them, or a misparsed small
  number will over-compact real conversations.
